# 毛概研习

《毛概》章节刷题网站，共 270 道题、9 个章节。

网站为纯静态站点，可直接部署到 GitHub Pages。练习记录使用浏览器 `localStorage` 保存，不会上传到服务器。

## GitHub Pages 部署

1. 在 GitHub 创建一个公开仓库。
2. 将此目录中的全部文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 打开仓库的 `Settings` → `Pages`。
4. 将 `Source` 设为 `Deploy from a branch`。
5. 选择 `main` 分支和 `/ (root)` 目录，点击 `Save`。
6. 等待 GitHub 构建完成，通过 `https://用户名.github.io/仓库名/` 访问。
